# Two Sum Solution
Given a list of numbers, find two numbers that add up to a target sum.
This solution uses a dictionary to store numbers and their indices, iterating through the list to find the complement of each number.
### Approach and Complexity
* Approach: Hash table iteration
* Time complexity: O(n)
* Space complexity: O(n)
* Runtime: 1 ms
* Memory: 13.2 MB
