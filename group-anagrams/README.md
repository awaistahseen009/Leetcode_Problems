# Group Anagrams Solution
This solution groups a list of strings into anagrams of each other.
### Approach
The approach used is to create a unique identifier for each group of anagrams by counting the frequency of each character, then use a dictionary to store the anagrams.
### Complexity
* Time complexity: O(NM) where N is the number of strings and M is the maximum length of a string
* Space complexity: O(NM)
* Runtime: 99 ms
* Memory: 16.3 MB
