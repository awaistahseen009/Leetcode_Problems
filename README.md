## 📘 Example Problem: Ceiling of a Number

### Problem Description
Find the smallest number in a sorted list that is greater than or equal to a given target number.

### Solutions
1. **Naive Approach**: Iterate through the list to find the ceiling.  
   **Time Complexity**: O(n)  
   **Space Complexity**: O(1)

2. **Optimized Approach**: Use binary search to find the ceiling in O(log n) time.  
   **Time Complexity**: O(log n)  
   **Space Complexity**: O(1)
