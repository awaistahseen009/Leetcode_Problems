# Top K Frequent Elements Solution
This solution finds the k most frequent elements in an array.
The approach used is a hash map to count element frequencies, then a min-heap to efficiently select the top k elements.
Time complexity is O(n log k) and space complexity is O(n), where n is the number of elements in the input array.
The provided python solution achieves a runtime of 8 ms and memory usage of 14.2 MB.
